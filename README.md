# photo_scripts
Bash scripts for adding and importing photos.

## Instructions
### Adding photos from google takeout
From google photos, get a takeout zip or tgz file that you want to add to an
existing directory of photos that is menaged by digikam.
* Run photo_extension_fixer.sh.  It takes a directory as input.  It will modify the
files in the input directory to correct any files that have the wrong extension
assigned.  Some photos are downloaded with a .jpeg extension but are actually .png.
* Run photo_meta_encoder.sh.  It takes a directory as input.  It will modify the
photo exif to add tags for the album to which the photo belonged.  Not all photos
belong to an album.  The input directory is specific to the google photos structure
and needs to be the "Google Photos" directory.
* Run MetaSort on the photo directory.  It will rearrange all the directories into
YYYY/MM format instead of albumm or other directories.  The album info was encoded to
the exif in the previous step so it can still be used to search with digikam.
MetaSort needs a desktop environment and has a wizard to walk through the process.
After buidling MetaSort, double click on Run_MetaSort.command.  MetaSort will need an
output directory and does not affect the originals.
* MetaSort may fail and produce a directory named "Unknown Time".  Try using
photo_date_marshaller.sh on this directory.  That script needs its own output
directory.  
* Use photo_rsync.sh to merge the output of photo_date_marshaller.sh with the output
of MetaSort.  Take care to select the corret parent directory for both required
options to the script.  This may be necessary for Photos and Videos.
* If photo_date_marshaller.sh fails on any phots you will need to resolve them
manually.

### Adding additional photos
This section describes how to add a directory of photos that were not generated by
google takeout.
* As described above, run the photo_extension_fixer.sh on the input directory.
* As described above, run the photo_date_marshaller.sh on the input directory.
* Move/merge the directories onto the /Volumes/T7/photos/photos and
/Volumes/T7/photos/videos directories.
